# DemoWebShop_Application_Automation

Automation testing project for Demo Web Shop using Selenium WebDriver, Java, TestNG, Page Object Model (POM), Data-Driven Testing, and Extent Reports.

---

## Project Overview

This project automates the testing of the Demo Web Shop application using Selenium WebDriver and Java.  
The framework is designed using the Page Object Model (POM) to improve code reusability, readability, and maintenance.

The project includes automation of major functionalities such as user registration, login, product search, add to cart, wishlist, and checkout process.
